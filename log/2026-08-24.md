# 2026-08-24

Added file-based log rotation to a Node.js logging setup: a retention limit so old files get pruned instead of accumulating forever, and restrictive permissions on the rotated files themselves. Also went back through the surrounding code and pulled a handful of magic numbers out into named constants while adding tests to pin down the new rotation behavior:

```ts
const LOG_RETENTION_COUNT = 5;
const LOG_FILE_MODE = 0o600; // owner read/write only

function rotate(logDir: string, baseName: string) {
  const files = listLogFiles(logDir, baseName).sort().reverse();
  for (const stale of files.slice(LOG_RETENTION_COUNT)) fs.unlinkSync(stale);
  const next = path.join(logDir, `${baseName}.${Date.now()}.log`);
  fs.writeFileSync(next, "", { mode: LOG_FILE_MODE });
  return next;
}
```
