Built a set of read-only tools exposing remote device log querying through an AI assistant interface, supporting single-device and batch queries with time windowing, text search, pagination, and automatic redaction of credential-like content. Two structured evaluation passes then exercised the tools against realistic operator scenarios, comparing results to a documented baseline from an earlier, cruder approach and measuring call counts, error rates, and wasted calls. The evaluations surfaced a concurrency bug: parallel reads against the same device could spuriously fail with a rate-limit error because the queueing window was too short, plus a secondary finding that a scan limit on search queries could return a misleading "no matches" result indistinguishable from a true empty result. The queue wait was extended and the tool descriptions updated to tell callers to serialize same-device reads; the fix was verified with a live test using a deliberately lowered rate limit and parallel calls to confirm the limiter still triggered correctly under real load. Full test suites passed afterward, after ruling out one unrelated flaky test.
