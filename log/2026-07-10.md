# 2026-07-10

A UI/CLI feature flag was being silently dropped instead of taking effect, which turned out to be a parameter-passing bug compounded by loose argument parsing — the flag was accepted syntactically but never actually threaded through to where it mattered. Fixed the plumbing, then hardened the CLI's flag validation so a similar drop would fail loudly instead of silently, and refactored a zip-extraction helper along the way. Verified against a live test device rather than trusting the unit tests alone.

Also wrote documentation for a newly added end-to-end test suite and flagged a gap in its CI integration compared to a sibling suite, and diagnosed an intermittent local network timeout during service startup as an environment race condition rather than a genuine bug.
