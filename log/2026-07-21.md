# 2026-07-21

An internal CLI tool had a stale default config path that silently broke credential resolution for a device-provisioning workflow — it pointed somewhere that used to be valid, failed quietly instead of erroring, and left whoever hit it to guess why credentials weren't being found. Fixed the path and documented the available credential setup options so the next person wouldn't have to reverse-engineer it. A follow-up test run was separately blocked by a placeholder value left in a config file that needed real credentials.

Also researched an existing codebase to fact-check a proposed internal design document, and published a written report noting that the design doc it referenced didn't actually exist and that several of the brief's technical assumptions were incorrect — better to say so plainly than let a plan get built on a document nobody could point to.
