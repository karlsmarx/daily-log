# 2026-08-07

Audited a device status-reporting service against an upstream schema to confirm every required field was either implemented or safely defaulted, and documented a boolean-vs-integer type mismatch bug found during the review.

Fixed a CLI argument-parsing bug where several legacy command wrappers were silently dropping user-supplied flags — each wrapper forwarded only a hardcoded subset of arguments to the underlying command instead of passing everything through:

```sh
# before: only two flags ever make it through, everything else is dropped
legacy-cmd() { real-cmd --verbose "$1" --format "$2"; }

# after: forward everything the caller actually passed
legacy-cmd() { real-cmd "$@"; }
```

Verified the fix across six command aliases, and confirmed a package's internal imports were already correctly split between a published module and local application code, validating the flow in a live simulator environment. A follow-up verification pass was blocked by the test host running out of resources.
