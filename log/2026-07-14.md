# 2026-07-14

Reorganized a branch's pending changes into logically separated commits for a test suite, and diagnosed/resolved a git working-tree tracking conflict that was blocking a rebase.

Separately, a device-provisioning CLI tool had an intermittent DNS resolution bug: on some networks the resolver would try an IPv6 address first, time out, and only then fall back to a working IPv4 one, adding a multi-second stall before every request. Fixed by forcing IPv4-first resolution instead of leaving it to the platform default:

```js
const dns = require('node:dns');
dns.setDefaultResultOrder('ipv4first');
```

Verified with the full test suite, then helped triage a downstream authentication error against an internal API by narrowing down likely credential/config mismatches.
