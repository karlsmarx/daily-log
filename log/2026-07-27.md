# 2026-07-27

Cleared a full round of code review feedback on a plugin system in one pass. The most substantial item was a path-traversal vulnerability: a plugin-supplied filename was being joined directly onto a base directory, so a crafted name containing `../` segments could resolve outside the intended directory. Fixed it by resolving the joined path and rejecting anything that lands outside the base directory rather than trying to sanitize the input string itself:

```ts
function safeJoin(baseDir: string, userPath: string): string {
  const resolved = path.resolve(baseDir, userPath);
  if (!resolved.startsWith(path.resolve(baseDir) + path.sep)) {
    throw new Error("path escapes base directory");
  }
  return resolved;
}
```

Also fixed a dependency-injection timing bug (a dependency was being read before the container had finished registering it) and tightened silent failure handling so a swallowed error surfaces instead of disappearing, and migrated a legacy monolith module into smaller scheduled-task-based modules. Verified everything with clean builds, lint checks, and a full test suite (108 tests), after working around an unrelated quirk in the test mocking library.
